# Russian IPTV
Collection of publicly available Russian IPTV (Internet Protocol television) channels.

## Usage
Simply copy the link below and paste it into any IPTV player.

```
https://github.com/naggdd/iptv/raw/main/ru.m3u
```

## Sources
The playlist was mainly compiled using the aggregator https://m3u.su and http://dmi3y-tv6.ru

Additionally, here is a list of repositories that deserve special attention.
