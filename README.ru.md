# Российский IPTV плейлист
Коллекция общедоступных российских IPTV каналов, собранных из разных источников в один плейлист.

## Использование
Скопируйте ссылку на плейлист и вставьте в любой IPTV плеер.

* Основной
  ```
  https://naggdd.github.io/iptv/ru.m3u
  ```
* Радиостанции
  ```
  https://naggdd.github.io/iptv/radio.m3u
  ```
* Мультфильмы
  ```
  https://naggdd.github.io/iptv/cartoons.m3u
  ```

## Поддержка
Этот плейлист составляется для показа в приложении [Волна ТВ](https://apps.apple.com/app/id6745237104) на iOS. Так что лучшая ваша поддержка - скачать приложение и поставить хороший отзыв.

Для тех, кто хочет поддержать развитие и актуальность плейлиста финансово - [DonationAlerts](https://dalink.to/nagd).
